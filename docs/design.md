# LabFlow Simulator

เครื่องมือทดลองการไหลของงานห้องปฏิบัติการสำหรับทีมเทคนิคการแพทย์ หน้าแรกเป็นแผนผังห้องแล็บสามมิติที่มีการเคลื่อนที่จริง คิวและสถานะอ้างอิงจาก simulation engine เดียวกับหน้าจอ LIS/HIS

สีพื้นขาวอมเขียวและ slate, สี teal สำหรับการทำงานปกติ, amber สำหรับคิว/รอ, rose สำหรับเหตุขัดข้อง และม่วงสำหรับข้อมูล ใช้ Noto Sans Thai กับตัวเลขแบบ tabular พื้นที่หลักให้กับห้องแล็บ ไม่มีหน้าโฆษณาหรือการ์ดตกแต่งที่ไม่ช่วยการทำงาน

ผู้ใช้เห็นเวลา ความเร็ว จำนวนผู้รับบริการ และงานค้างก่อน เลือกผู้ป่วยแล้วติดตามเส้นทางผู้ป่วย สิ่งส่งตรวจ และผลตรวจที่เชื่อมกัน หรือเปิด LIS เพื่ออนุมัติ/แจ้งค่าวิกฤต/แก้ไขผล เปิดแผงตั้งค่าเพื่อปรับทรัพยากรและระบบขนส่ง ทุกค่าเริ่มต้นระบุว่าเป็นค่าจำลอง สามารถส่งออก/นำเข้าพารามิเตอร์จริงได้

หลักการ: สถานะที่เห็นต้องตรงกับเหตุการณ์ใน engine; การปล่อยผลต้องตรวจเงื่อนไขทุกครั้ง; ความเร็วภาพไม่เปลี่ยนผลจำลอง; การเลือกและควบคุมใช้คีย์บอร์ดได้; มือถือเปลี่ยนเป็นแนวตั้งและคงเครื่องมือหลัก; reduced motion ลดภาพเคลื่อนไหวโดยไม่เปลี่ยนเวลา engine

ตรวจ brief: ครอบคลุมขึ้นบัตรถึง HIS, แยกบันทึก LIS กับอนุมัติ, กระสวยมีเที่ยว/ความจุ/เส้นทาง/ส่งสำรอง, เชื่อม patient/encounter/order/specimen, มีหลักฐานและคำอธิบายขอบเขตในแอป
