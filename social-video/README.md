# LabFlow social video kit

วิดีโอสาธิต LabFlow สำหรับ Facebook, Instagram Reels และการนำเสนอ ใช้ฉาก 3D และระบบจำลองเดียวกับแอปจริง ถ่ายด้วยกล้องที่เคลื่อนต่อเนื่องและเวลาแบบ deterministic ไม่ใช่สไลด์ภาพนิ่ง

## Deliverables

- `deliverables/LabFlow-portrait-44s.mp4` — 1080 × 1920, 9:16, 44 วินาที, 30 fps
- `deliverables/LabFlow-landscape-44s.mp4` — 1920 × 1080, 16:9, 44 วินาที, 30 fps
- Poster PNG ทั้งสองอัตราส่วน
- `deliverables/LabFlow-th.srt` — คำบรรยายภาษาไทยแยกไฟล์
- `deliverables/manifest.json` — ข้อมูลการผลิตและลำดับบท

ทั้งสองวิดีโอใช้ H.264, yuv420p และ faststart พร้อมข้อความไทยฝังในภาพ ไม่มีเสียงหรือเพลง จึงดูแบบปิดเสียงได้ และสามารถเลือกเพิ่มเพลงจากคลังของแพลตฟอร์มเมื่อโพสต์เอง

## Reproduce

Place this folder inside the repository with `dist/` in its parent, or beside a `simulator` folder. To override discovery, set `LABFLOW_SIMULATOR_ROOT` to the simulator root containing `dist/`. Install Python dependencies: `pip install playwright imageio-ffmpeg`; then `python -m playwright install chromium`.

Run `python produce.py`. It starts a temporary loopback HTTP server on port 4175, loads local app assets, renders through Chromium WebGL/SwiftShader, encodes VP8 intermediate frames with WebCodecs, renders Thai typography through Chromium, and composites H.264 deliverables with FFmpeg. Run `python produce.py --encode-only` to recomposite existing intermediates. Remove only the generated `intermediates/scene.ivf` when camera or simulation changes require recapture.

The six camera chapters cover overview, collection, transport/outage, preparation/analyzers, result workflow and the final invitation. The engine uses default configuration, a 900-second warmup and 30× simulation time. Tube outage begins at video 16 seconds and recovers at 21 seconds; resulting queues and transport are generated by the engine. Camera interpolation and person/specimen motion update at 30 fps. Captions explain the simulated processes and do not claim measured improvements or live hospital performance.

No patient data, third-party music, credentials or live HIS connections are included. Blender model provenance and licenses remain in the simulator repository.
